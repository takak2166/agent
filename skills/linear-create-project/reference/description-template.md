# 任意の Project `description` スケルトン

ユーザーがテーマだけ渡して Markdown 構成がほぼ無いときに使う。**空の見出しは省略**してよい。MCP には **`SKILL.md` の Prerequisites** どおり、**字面の改行どおり**渡す（エスケープ列にしない）。

```markdown
## 背景

[なぜこの Project が必要か。元メモ・Cosense の文脈・チャットの要約など。]

## ゴール

[この長期テーマとして「それなりにできている」状態の説明。]

## 着手候補

* [具体的な次の一手 1]
* [具体的な次の一手 2]

## リンク

* [関連 URL]
```
