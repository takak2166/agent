# Issue の `description` テンプレート

**`linear-create-issue`** 向け。**`save_issue`** の **`description`** にそのまま使える Markdown。**字面の改行どおり** MCP に渡す（エスケープ列にしない）。

## どの粒度で何を使うか

| 粒度 | 使うセクション |
|------|----------------|
| フル（計画済み〜受け入れ条件あり） | 下記「デフォルト（フル）」のすべて |
| 軽量（バックログの思いつき） | `## 背景` / `## 目的` / `## リンク` のみ |
| 学習・読書など | `目的` と `受け入れ条件` に期限・学習リンク・読了の定義を書く |

Linear が誤自動リンクするような **裸のファイル名っぽい文字列**は避け、言い換える。

---

## デフォルト（フル）

コピー用:

```markdown
## 背景

[なぜこの Issue が必要か。元メモや依頼の文脈。]

## 目的

[完了したときに何ができているか。]

## 受け入れ条件

* [確認できる完了条件 1]
* [確認できる完了条件 2]

## リンク

* [関連 URL や元メモ]

## メモ

[制約、優先順位、後で見返す補足。不要なら省略。]
```
